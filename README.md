# Projet UA3 - Gestion de flotte de véhicules

## Description

Ce projet est une application Java permettant de gérer une flotte de véhicules.

L'application permet :

- Lire les véhicules depuis un fichier CSV
- Ajouter les véhicules dans une flotte
- Louer un véhicule
- Retourner un véhicule
- Gérer les entretiens
- Afficher des statistiques
- Générer un rapport texte

## Technologies

- Java
- IntelliJ IDEA
- Programmation Orientée Objet
- CSV
- GitHub
